# Swords-Into-Plowshares-Text-Game
改编于《太平年》和五代十国历史的文字冒险游戏。只需浏览器，无需安装和配置。可选择钱弘俶| 赵匡胤| 郭荣体验不同抉择和命运变局。A historical text adventure game about the Chinese Ancient Era. Make choices, shape destiny.

## 🧠 产品思维 & 游戏化设计 Product senese＆ Game experience design
| 特性 | 设计思路 |
|------|----------|
| ⏰渐入动画和打字机特效 | 开场页的地图使用CSS动画实现缓慢浮现的效果，淡入动画能营造一种历史画卷缓缓展开的仪式感。为游戏文本加入打字机特效伴随音效逐步浮现，有游戏交互和文字游戏的体验感 |
| 🗡鼠标样式和点击移动效果 | 使用中国剑的鼠标指针替换默认指针，增强游戏的历史武侠氛围。设计了点击效果和移动粒子拖尾渐隐渐散，营造残影效果 |
| 🎵浏览器实时生成音效 | 音效伴随点击等操作，由Web Audio API用浏览器生成无需任何音频文件和外链 |
| 👨3个角色和10+结局 | AI依照五代十国和电视剧背景，为3个人物生成不同初始数值和剧情、选项，营造游戏主动性和结局多样性 |
| 📊UI和血条动画 | 角色有图片和血条，每点一个选项，立刻看到数值变化+新剧情，1秒内血条动画过渡 |
