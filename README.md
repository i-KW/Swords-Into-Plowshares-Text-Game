## 游戏背景与人物

### 历史背景

游戏设定在**五代十国末期（公元 959 年，后周显德六年）**。这是中国历史上一个大分裂、大动荡的时期——中原王朝更迭如走马灯，江南十国割据偏安。与此同时，统一的历史潮流已暗流涌动。

### 可选人物

| 人物 | 身份 | 初始数值 | 核心矛盾 | 历史原型 |
|------|------|---------|---------|---------|
| **钱弘俶** | 吴越王（钱九郎） | 民心 80 / 兵力 50 / 体力 70 | 保境安民 vs 胡进思权欲膨胀 | 吴越末代君主，纳土归宋的真实历史人物 |
| **赵匡胤** | 后周殿前都点检 | 民心 60 / 兵力 90 / 体力 80 | 忠君报国 vs 黄袍加身 | 北宋开国皇帝，陈桥兵变的历史主角 |
| **郭荣** | 后周世宗 | 民心 70 / 兵力 80 / 体力 60 | 北伐大业 vs 英年早逝 | 后周世宗柴荣（郭荣），五代第一明君 |

### 数值系统

三个核心数值驱动游戏走向：

- **民心**（绿色）：影响百姓支持度，民心满（≥100）可触发和平结局
- **兵力**（红色）：军事实力，高兵力可触发统一结局，兵力过低（≤10）将导致亡国
- **体力**（蓝色）：君主身体状况，体力过低（≤10）将因积劳成疾而结束游戏

数值范围钳制在 **0-100** 之间。

## 游戏结构与玩法

### 整体架构

```
开场页（历史背景介绍）
    │
    ▼
主公选择页（三选一）
    │
    ▼
游戏主页面 ──► 每阶段展示：剧情文字 + 提示 + 2~4 个选项
    │                            │
    │         用户选择后触发数值变化，推进下一阶段
    │                            │
    └──── 数值达标或剧情推进到终点后 ──► 结局页（15+ 种结局变体）
```

### 剧情结构

每位主公的剧情分为 **3 个阶段**：

1. **阶段一**——初始抉择（4 条分支路径）
2. **阶段二**——核心剧情发展（每条路径有 2-4 个后续选项）
3. **阶段三**——结局收敛（根据前两阶段的选择触发不同结局）

### 结局系统

游戏共有 **15 种以上的结局**，包括：

- **太平结局**：江南太平、太平明君、藩王太平
- **战争结局**：吴越悲歌、割据福建、吴越抗宋
- **个人结局**：归隐太平、隐忍称王、归隐江湖
- **功业结局**：北宋开国、北伐功成、一统天下
- **悲剧结局**：忠烈王、积劳成疾、英年早逝、众叛亲离

**双重触发机制**：
1. **剧情触发**：通过选项推进到阶段三，根据选项 ID 映射到对应结局
2. **数值触发**：`checkEnding()` 函数在每个选项后检查数值是否达到阈值

#### 钱弘俶的特殊设计：子路径追踪

钱弘俶是剧情分支最复杂的角色，采用 **`qianPath` 变量** 追踪玩家在阶段一的选择：

```javascript
qianPath = 'expand'    // 扩军备战
qianPath = 'soothe'    // 安抚百姓
qianPath = 'probe'     // 试探北宋
qianPath = 'incognito' // 微服私访
```

阶段二的剧情分发根据 `qianPath` 路由到独立的处理函数，避免传统 `if-else` 链中路路径交叉导致的故事错位问题。（*这一设计是在修复了早期版本中所有路径共享同一个错误处理器的 Bug 后引入的。*）

## 鼠标指针设计：剑形 SVG 光标

### 设计思路

为了配合游戏的历史武侠氛围，默认鼠标指针被完全隐藏（`cursor: none`），取而代之的是一把**中国剑（剑）**的 SVG 矢量图形，作为自定义光标跟随鼠标移动。

### 实现方式

直接在 HTML 中嵌入 **内联 SVG** 元素，由几个几何部件组成：

```
              ▲
             / \         ← 剑刃（渐变金属色三角形）
            /   \
           ─────         ← 护手（棕色圆角矩形）
           │   │
           │   │         ← 剑柄（深色矩形 + 缠带纹路）
           │   │
            ●           ← 剑首 + 红宝石（金色圆 + 红点）
```

```html
<svg class="custom-cursor" width="24" height="28" viewBox="0 0 24 28" ...>
  <!-- 剑刃 polygon -->
  <!-- 剑脊线 line -->
  <!-- 护手 rect -->
  <!-- 剑柄 rect + 缠带纹路 lines -->
  <!-- 剑首 circle + 宝石 circle -->
</svg>
```

**关键 CSS：**

```css
.custom-cursor {
    position: fixed;
    pointer-events: none;   /* 不阻挡下层点击事件 */
    z-index: 9999;
    transform: translate(-4px, -4px) rotate(-45deg);  /* 剑尖指向鼠标热点 */
    filter: drop-shadow(...);
    transition: transform 0.08s ease;
}
```

### 交互反馈

- **点击效果**：添加/移除 `.click` 类，缩小至 80%，模拟挥剑时的顿挫感
- **移动跟随**：`mousemove` 事件实时更新 `left` / `top` 像素位置
- **粒子拖尾**：鼠标移动时在路径上生成棕色半透明粒子，渐隐渐散，营造残影效果

### 选择 SVG 而非 CSS 形状的原因

| 方案 | 优点 | 缺点 |
|------|------|------|
| CSS 三角形 | 纯 CSS，零资源 | 形状简陋，无法表现剑的细节 |
| Unicode 字符 🗡️ | 一行代码 | 跨平台渲染不一致，分辨率低 |
| PNG 图片 | 细节丰富 | 多一个 HTTP 请求，缩放模糊 |
| **SVG 内联** ✅ | **矢量无损、细节丰富、零请求、可 CSS 控制、颜色可控** | 代码稍长 |

## 打字机效果与图片呈现

### 打字机效果

每段剧情文字都以**打字机动画**逐字输出：

```javascript
function typeWriter(elementId, text, callback) {
    // 1. 锁定选项按钮（防止打字期间误操作）
    lockOptions();

    // 2. 创建闪烁光标元素
    const typingCursorElem = document.createElement('span');
    typingCursorElem.className = 'typing-cursor';  // CSS 闪烁动画

    // 3. 逐字输出（每个字符 20ms 间隔）
    function typeChar() {
        if (i < text.length) {
            // 替换光标为字符，再在末尾重新添加光标
            element.innerHTML = element.innerHTML
                .replace(/<span class="typing-cursor"><\/span>$/, char);
            element.appendChild(typingCursorElem);
            i++;
            playTypewriterSound();  // 每字一音效
            setTimeout(typeChar, typingSpeed);
        } else {
            // 完成：移除光标，解锁按钮，执行回调
            typingCursorElem.remove();
            unlockOptions();
            callback?.();
        }
    }
}
```

**设计要点：**

- **光标闪烁**：通过 CSS `@keyframes blink` 实现 `opacity` 交替
- **换行处理**：`\n` 字符转换为 `<br>` 标签
- **错误恢复**：`try-catch` 包裹，异常时释放锁定，保证 UI 不卡死
- **锁机制**：`isTyping` 布尔值避免重复触发，`isOptionsLocked` 禁用选项按钮

### 图片系统

游戏使用三类图片：

| 类型 | 源文件 | 出错兜底 |
|------|--------|---------|
| **角色头像** | `钱弘俶.png`、`赵匡胤.png`、`郭荣.png` | `display:none` |
| **势力 Logo** | `wuyue_logo.png` 等 | 显示 CSS 文字 Logo（蓝/红/黄色块） |
| **五代十国地图** | `map.jpg` | `display:none`（隐藏） |

所有图片都通过 `onerror` 事件处理加载失败的情况，确保即使资源缺失，游戏核心功能不受影响。

### 地图呈现

开场页的五代十国地图使用 CSS 动画获得**缓慢浮现**的效果：

```css
.dynasties-map {
    opacity: 0;                              /* 初始不可见 */
    animation: slowFadeIn 3s ease-out forwards;  /* 仅一次淡入 */
    margin: 0 auto;                          /* 居中 */
}

@keyframes slowFadeIn {
    0%   { opacity: 0; }
    100% { opacity: 1; }
}
```

区别于普通页面加载的"瞬间出现"，3 秒的淡入动画能营造一种**历史画卷缓缓展开的仪式感**。

## 音效设计与实现：Web Audio API

### 为什么选择 Web Audio API

游戏的音效最初计划使用外部音频文件（WAV/MP3），但遇到了以下问题：

1. **本地文件缺失**：`mixkit-hard-typewriter-click-1119.wav` 不存在
2. **防盗链封锁**：Mixkit 等免费音效网站返回 HTTP 403
3. **文件体积**：即使一个短音效也有几十 KB

**解决方案：放弃外部文件，用 Web Audio API 程序化生成音效。**

### Web Audio API 音效生成原理

Web Audio API 允许浏览器**实时合成音频**，无需任何音频文件。核心概念：

```
振荡器 (OscillatorNode)  ──►  音量控制器 (GainNode)  ──►  音频输出 (destination)
     ↑                               ↑
  波形类型 + 频率                 音量随时间变化
```

### 两种音效的设计

#### 点击音效（`playClickSound`）

```javascript
osc.frequency.value = 660       // 频率 660Hz（较明亮）
osc.type = 'square'              // 方波（清脆、有"咔嗒"感）
gain.gain.setValueAtTime(0.12, now)        // 起始音量 12%
gain.gain.exponentialRampToValueAtTime(0.001, now + 0.06)  // 60ms 内衰减至零
```

- **时长**：60ms
- **听感**：短促清脆，类似按键或鼠标点击
- **用途**：按钮点击、选项选择

#### 打字音效（`playTypewriterSound`）

```javascript
osc.frequency.value = 400 + Math.random() * 200  // 400-600Hz 随机
osc.type = 'sine'              // 正弦波（柔和）
gain.gain.setValueAtTime(0.04, now)       // 音量 4%（很轻）
gain.gain.exponentialRampToValueAtTime(0.001, now + 0.03)  // 30ms 衰减
```

- **时长**：30ms
- **听感**：极轻的"嗒"声，每字音高微变，模拟机械打字机的随机感
- **用途**：打字机每个字符输出时触发

### 关键实现细节

**惰性初始化**：

```javascript
let audioCtx = null;
function getAudioCtx() {
    if (!audioCtx) {
        audioCtx = new (window.AudioContext || window.webkitAudioContext)();
    }
    if (audioCtx.state === 'suspended') audioCtx.resume();
    return audioCtx;
}
```

- AudioContext 在页面加载时**不创建**，首次点击时延迟创建
- 避免浏览器自动播放策略拦截
- 兼容 Safari 的 `webkitAudioContext` 前缀

**指数衰减**（`exponentialRampToValueAtTime`）：

音量不是瞬间切断而是指数衰减，能消除"爆音"（click/pop noise），让音效听起来更自然。

### Web Audio API vs 传统音频文件

| 维度 | 音频文件 | Web Audio API（本游戏） |
|------|---------|----------------------|
| 网络依赖 | 需要加载文件 | **零依赖，离线可用** |
| 文件体积 | 几十 KB | **0 KB** |
| 防爬虫/防盗链 | 可能失效 | **不受影响** |
| 音色变化 | 固定录音 | **可程序化变化**（如随机音高） |
| 实现复杂度 | 简单（放个 `<audio>`） | 稍高（需写生成代码） |
| 音质 | 录音级真实音质 | 合成感（电音） |

> **适合场景**：游戏中的 UI 音效、提示音、简单反馈音非常适合用 Web Audio API。而背景音乐、语音、真实环境音则仍需音频文件。

## 开发历程与 Bug 修复记录

本游戏在开发过程中经历了一次重要的 Bug 修复（`main.txt` → `main.html`），主要修复了：

1. **结构性 Bug**：钱弘俶分支路径混乱，所有阶段二选项共用一个错误处理器 → 引入 `qianPath` 子路径追踪 + 独立处理函数
2. **数值 Bug**：赵匡胤结局条件 `bingli >= 110` 因数值钳制永远无法触发 → 改为 `>= 100`
3. **死代码**：`handleQianOption` 中 `optionId === 5` 分支不可达 → 已删除重构
4. **光标冲突**：打字机内部变量 `cursor` 遮蔽全局剑形光标 → 重命名为 `typingCursorElem`，全局改为 `swordCursor`
5. **资源路径**：图片路径从英文名改为中文名，匹配实际文件
6. **音效方案**：外部音频文件 → Web Audio API 程序化生成
