# Swords-Into-Plowshares-Text-Game
改编于《太平年》和五代十国历史的文字冒险游戏。只需浏览器，无需安装和配置。可选择钱弘俶| 赵匡胤| 郭荣体验不同抉择和命运变局。A historical text adventure game about the Chinese Ancient Era. Make choices, shape destiny.
